# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.4.0] - 2026-10-10

### Added

- OpenAPI layout with Quick Start and API keys pages, plus a create/update key modal.
- Created API key value shown in a prompt with a copy action.
- Auto-growing textarea in the preview/debug chat (Enter to send, Shift+Enter for a newline).
- Regenerate an answer in place.
- Persisted suggested follow-up questions across page refresh.
- Code highlight component and document preview drawer.

### Fixed

- Nav underline active state now uses `exact-active-class`.
- Chat message list height collapse in the preview/debug panel.

## [0.3.1] - 2026-10-03

### Added

- Debug chat UI with markdown streaming and an agent thought panel.

## [0.3.0] - 2026-08-25

### Added

- Dataset/document views, add-document modal, and English UI.

## [0.2.0] - 2026-07-12

### Added

- Initial front-end with basic pages and plugin interfaces.
